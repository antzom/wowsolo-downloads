# WoW Solo 0.01 — установка только сервера

Пакет для Windows x64 включает сервер WoW Solo, локальную базу MySQL, необходимые компоненты и лаунчер. Игровой клиент устанавливается отдельно. Подойдёт совместимый клиент **Wrath of the Lich King 3.3.5a, сборка 12340**, в том числе русский (`ruRU`). Храните клиент в отдельной папке за пределами каталога установки сервера.

## 1. Установите и запустите сервер

1. Распакуйте пакет целиком. Рядом с установщиком должны остаться папки `Payload`, `Database` и `Installer`.
2. Запустите **WoWSolo-Server-Setup-0.01.exe**, выберите русский язык и новую папку установки. Дождитесь завершения импорта базы.
3. Откройте ярлык **WoW Solo Server** на рабочем столе. Во вкладке **Управление сервером** нажмите **Запустить всё** и дождитесь статуса **Готово**.
4. Во вкладке **Консоль сервера** выберите шаблон **Создать учётную запись**, подставьте свой логин и пароль и выполните полученную команду в окне worldserver без точки в начале. Для друзей создайте отдельные игровые учётки. Данные администратора лежат в `Control\First-Login.txt` в папке установки. Храните их у себя.

Это предварительная сборка для чистой установки. Если WoW Solo уже установлен, используйте другой ПК или виртуальную машину. Обе сборки используют службу `WoWSoloMySQL`.

## 2. Подключите свой клиент

1. Откройте `Data\ruRU\realmlist.wtf` в папке клиента и сохраните копию исходного файла. Для английского клиента ищите этот файл в `Data\enUS` или `Data\enGB`.
2. Если сервер запущен на том же ПК, укажите в файле строку:

   ```text
   set realmlist 127.0.0.1
   ```

   Если подключаетесь к другу, впишите вместо `127.0.0.1` адрес, который он сообщит.
3. Запустите **Wow.exe**, войдите под созданной учётной записью и выберите мир **WoWSolo**.
4. Чтобы добавить панель **Спутники**, скопируйте папку `Optional\WoWSoloBots` из пакета в `Interface\AddOns` клиента. На экране выбора персонажа откройте **Модификации** и включите **WoWSoloBots**. Панель также можно установить через вкладку **Управление клиентом** в лаунчере, указав путь к своему клиенту.

## Если играете с друзьями

Владелец сервера во вкладке **Сеть** указывает IP-адрес, доступный друзьям по общей локальной сети или VPN, и нажимает **Применить адрес**. Друзья указывают тот же адрес в своём `realmlist.wtf`. Для игры нужны TCP-порты **3724** и **8085**. MySQL и SOAP оставьте для локального доступа.

Чтобы завершить работу сервера, нажмите **Остановить всё** во вкладке **Управление сервером**.
