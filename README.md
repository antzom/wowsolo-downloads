## Установка / Setup

- **Сервер и клиент / Server + client.** Распакуйте архив целиком и запустите `WoWSolo-Setup-0.01.exe`. Extract the entire archive and run the installer.
- **Только сервер / Server only.** Распакуйте ZIP и запустите `WoWSolo-Server-Setup-0.01.exe`. Подключите отдельный клиент **Wrath of the Lich King 3.3.5a (12340)**. Extract the ZIP, run the server setup and use a separate **3.3.5a (12340)** client. [Инструкция RU](START_HERE_RU.md) · [EN guide](START_HERE_EN.md).
- **Графика / Graphics.** Дополнение для русского клиента 3.3.5a. Распакуйте ZIP целиком, запустите `WoWSolo-HD-Graphics-Setup.exe` и выберите модули. Для полного или частичного отката используйте `Client/.WoWSolo-Graphics/WoWSolo-Graphics-Uninstall.exe`. Optional pack for the Russian 3.3.5a client. The ZIP includes RU/EN guides and asset credits. [Описание и авторы / Release notes and credits](https://github.com/antzom/wowsolo-downloads/releases/tag/graphics-v0.2.1).
- **Патч «5000 ботов» / Bots5000 patch.** Для прежней установки с лаунчером 0.1.19. В серверной сборке 0.1.20 этот лимит уже включён. For launcher 0.1.19 installations. Server release 0.1.20 already includes this limit.
